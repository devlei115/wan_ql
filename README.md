## 🛒 京东脚本使用说明

### 1. 获取京东 Cookie
浏览器登录 [京东](https://m.jd.com) 后，在开发者工具 Network 中复制任意请求的 Cookie，或使用浏览器插件获取。

Cookie 格式：`pt_key=xxx;pt_pin=xxx;`

### 2. 配置环境变量
在青龙面板中创建环境变量：
- **变量名**: `JD_COOKIE`
- **变量值**: 你的京东 Cookie（多账号用 `&` 分隔）

### 3. 功能说明
- **京豆签到**: 每日签到领京豆
- **PLUS签到**: PLUS会员每日签到领奖励
- **店铺签到**: 自动签到10+家京东店铺
- **金融签到**: 京东金融每日签到
- **价格保护**: 自动查询可价保订单并申请
